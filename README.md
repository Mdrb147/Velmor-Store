# 🛍️ VELMOR STORE — واجهة المتجر وتجربة المستخدم

مستودع كود وتصميم متجر **VELMOR STORE** الرقمي.

هذا المستودع مخصص لتطوير واجهة الموقع (Frontend)، تحسين تجربة المستخدم (UI/UX)، تناسق التصميم، والأنيميشن على أجهزة الموبايل والكمبيوتر.

---

## 🚀 تشغيل المتجر محلياً وتجربة التعديلات (Local Preview)

يمكنك تشغيل المتجر ورؤيته يعمل بكامل ميزاته وبيانات المنتجات التجريبية على جهازك:

### لمستخدمي Windows:
* اضغط نقرتين على ملف **`run_preview.bat`**.
* سيفتح المتجر تلقائياً في متصفحك على: `http://localhost:8000`.

### عبر موجه الأوامر (Terminal):
```bash
python mock_server.py
```

---

## 🔄 تحديث التعديلات على السيرفر والدومين الحي

بمجرد الانتهاء من أي تعديل وتجربته محلياً:

### الطريقة السريعة (Windows):
* اضغط نقرتين على **`update_domain.bat`**.
* اكتب وصفاً بسيطاً لتعديلاتك واضغط Enter، وسيتم رفعها مباشرة.

### عبر Git في التيرمينال:
```bash
git add .
git commit -m "تعديل تصميم كروت المنتجات والقوائم"
git push origin main
```

---

## 📁 هيكل الملفات

* **`index.html`**: الصفحة الرئيسية للمتجر، تصفح المنتجات والأقسام، شاشات الشراء والمحفظة.
* **`admin.html`**: لوحة تحكم إدارة المتجر وتعديل الإعدادات والمنتجات.
* **`assets/store.css`**: ملف التنسيق والألوان والخطوط (يشمل الوضع النهاري والليلي Dark Mode).
* **`assets/store.js`**: التفاعل البرمجي، البحث، الفلاتر، السلة، والمودالات.
* **`assets/admin.css` & `admin.js`**: تنسيقات وبرمجة لوحة الأدمن.
* **`assets/brands/`**: شعارات وأيقونات الشركات والبراندات (ChatGPT, Canva, Adobe, etc.).
* **`assets/icons/`**: أيقونات الواجهة.
* **`mock_server.py`**: سيرفر محلي خفيف يحاكي الباكيند ويعرض منتجات وأقسام تجريبية.
